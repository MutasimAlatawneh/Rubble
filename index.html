Interactive Web Security Sandbox

Break it. See why. Fix it.

Ghurir is three small labs that each show one real web vulnerability. You press a button, watch the bug happen, then flip to the fixed code and watch the exact same attack fail.

🛡️

Everything here is a simulation. All code runs only inside your own browser tab. Nothing is sent to a server, nothing is stored, and no real passwords or personal data are involved.

How every lab works

  1. What it is — the idea in three sentences.
  2. The line — real code with the one buggy line highlighted.
  3. Try it — press a payload button and watch the attack live.
  4. Why it matters — what damage it does in the real world.
  5. The fix — flip Vulnerable ↔ Fixed and rerun the same payload.
  6. Sources — where to read more.
